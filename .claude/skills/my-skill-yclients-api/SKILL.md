# YClients API — прямой доступ из сессии

Claude Code ходит в интернет сам, поэтому для чтения YClients не нужен ни Apps Script, ни
clasp, ни браузер. Нужны только два токена.

## Ключи

| что | где лежит | статус |
|---|---|---|
| `PARTNER_TOKEN` | Drive → COWORK → «Токен API для Yclients.docx» (id `1Mc49vuHNT-VNcqzB9bpo8SKaPZwtur1x`) | рабочий, проверен |
| `USER_TOKEN` | Drive → тот же файл (Ирина дописывает) ИЛИ Apps Script → Настройки проекта → Свойства скрипта | живёт долго, но протухает при смене пароля техпользователя |
| `COMPANY_ID` | `328251` | — |

Технический пользователь YClients заведён специально под интеграции, это не личный аккаунт.

**Пароли не используются никогда.** `POST /auth` (login+password) — не наш путь: новый
`USER_TOKEN` получает Ирина, Claude только читает готовый.

### Порядок в начале сессии
1. Прочитать файл с токенами из Drive (`mcp__Google_Drive__read_file_content`).
2. Положить их во временный `~/.yclients.json` (контейнер сессии, в git не попадает):
   `{"partner": "...", "user": "...", "company": 328251}`
3. Проверить: `python3 yc.py whoami` → должно ответить `OK: EL\`NATUREL (id 328251)`.

`401 «Не указан идентификатор пользователя»` = протух **USER_TOKEN** (PARTNER_TOKEN при этом
может быть в порядке — проверяется запросом `/company/328251` вообще без user-токена).

## Как пользоваться

`yc.py` лежит рядом с этим файлом.

```bash
python3 yc.py whoami                      # проверка ключей
python3 yc.py goods                       # весь каталог (постранично)
python3 yc.py good DS32                   # карточка по артикулу / good_id / части названия
python3 yc.py get "/goods/328251?page=1"  # любой GET, сырой JSON
python3 yc.py storages                    # склады
```

Из кода: `import yc; yc.get(path)`, `yc.goods()`, `yc.find('StraDerm')`.

## Границы

- **Только чтение.** POST/PUT/DELETE в YClients из этого скила не делаем: приходы, продажи и
  списания идут через свои изолированные интеграции (финансы, Тильда, Ozon), чтобы не разъехались
  журналы и подписи документов. Понадобилась запись — сначала согласовать с Ириной.
- Лимит YClients — **5 запросов в секунду**; в `yc.py` пауза 250 мс и повтор при 429.
- `/goods` отдаёт ~25 позиций на страницу, `count` не расширяет → всегда листать до пустой.
- Токены — не коммитить, не печатать в ответах, не класть в файлы репозитория.

## Что уже известно про товары (из рабочей интеграции Тильды)

- `GET /goods/{company}` — каталог; `GET /goods/{company}/{good_id}` — одна карточка.
- Остаток по складу — в массиве `actual_amounts` (`storage_id` → `amount`).
  Склад магазина `637823` (`for_sale=1`), расходники салона `637822`.
- Цена, которую интеграция отдаёт на сайт, — поле `cost`.
- ❗ Где именно лежит **наценка/себестоимость** — на живых данных пока не смотрели.
  Первый же успешный `yc.py good <артикул>` покажет полный набор полей — записать сюда.
